# Local Archive

This folder holds original sources and retired material that the production website does not import. Everything here is ignored by Git except this index. Keep originals intact; publish a separate copy or optimized derivative under `src/assets/` or `public/`.

- `source-media/astragalus-project/` - CTB manuscript, presentations, source team photograph (`group.png`), and research specification. The original one-slide workflow remains `新建 PPTX 演示文稿 (2).pptx`.
- `source-media/astragalus-project/patent/` - Astragalus patent specification and application notices.
- `source-media/mechanics-project/` - mechanics research and patent documents.
- `source-media/physics-club-originals/` - original club photographs and demonstration videos.
- `source-media/website-originals/` - original website, profile, project, and hero media.
- `reference/` - downloaded example sites, standalone component examples, and local tool configuration.
- `generated/` - retained presentations, editorial audits, and historical browser-QA output.
- `legacy-homepage/` - components and media from the previous homepage implementation.

The published Astragalus photographs and workflow figures live in `src/assets/project-media/astragalus/`. Its downloadable PowerPoint lives in `src/assets/documents/astragalus/ctb-study-pipeline.pptx`. Current browser checks go in `output/playwright/<project-or-task>/`; temporary conversions and renders go in `tmp/`. Both locations are ignored. Move generated work into `archive/generated/` only when retaining it as historical reference.
